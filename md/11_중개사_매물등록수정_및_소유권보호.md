# 중개사 매물 등록·수정 및 소유권 보호

## 작업 결과

활성 중개사 계정이 매물 초안을 등록하고 자신의 매물 목록을 확인·수정하는 API와 웹 화면을 연결했다. 저장 시 부동산, 주소, 매물, 가격 이력, 상태 이력, 감사 기록을 하나의 DB 트랜잭션으로 처리한다. 다른 중개사의 매물은 존재 여부도 노출하지 않으며, 버전이 오래된 수정은 `409 Conflict`로 거절한다.

## 구성 요소의 역할과 필요한 이유

| 구성 요소 | 역할 | 필요한 이유 |
|---|---|---|
| 중개사 역할 Guard | 인증 사용자의 역할이 `AGENT`인지 검사 | 일반 회원이 URL이나 API를 직접 호출해 매물을 만드는 것을 막기 위해 필요 |
| 활성 프로필 검사 | 중개사·중개사무소·계정이 모두 활성 상태인지 검사 | 정지되거나 폐업한 주체가 새 매물을 등록하지 못하게 하기 위해 필요 |
| 소유권 조건 | 로그인 사용자와 연결된 `agentId`를 조회·수정 조건에 포함 | UUID를 알아내도 다른 중개사의 매물을 읽거나 바꾸지 못하게 하기 위해 필요 |
| 초안 기본 상태 | 새 매물을 항상 `DRAFT`로 생성 | 검수되지 않은 입력이 공개 목록에 즉시 노출되는 일을 막기 위해 필요 |
| 낙관적 잠금 `version` | 읽은 버전과 DB 버전이 같을 때만 수정하고 성공 시 1 증가 | 두 창이나 두 사용 흐름이 서로의 최신 수정을 조용히 덮어쓰지 않게 하기 위해 필요 |
| DB 트랜잭션 | 부동산·주소·매물·이력을 모두 성공시키거나 모두 취소 | 일부 데이터만 저장되어 불완전한 매물이 남는 것을 막기 위해 필요 |
| 가격 규칙 | 매매·전세·월세 유형에 맞는 가격 필드 조합을 검사 | 매매인데 월세가 있거나 전세 보증금이 없는 모순된 데이터를 차단하기 위해 필요 |
| 변경·가격 이력 | 생성과 수정 시점의 버전과 가격을 별도 기록 | 검수·분쟁·운영 조사에서 변경 경로를 확인하기 위해 필요 |
| 감사 로그 | 행위자, 대상 매물, IP HMAC 지문을 기록 | 보안 사고나 오작동 조사 시 누가 어떤 작업을 했는지 추적하기 위해 필요 |
| CSRF·Origin·JSON 검사 | 쿠키 인증 쓰기 요청의 출처와 토큰·콘텐츠 형식을 검사 | 악성 사이트가 로그인된 브라우저를 이용해 몰래 매물을 생성·수정하는 일을 막기 위해 필요 |
| 중개사 관리 화면 | 내 매물 목록, 신규 등록, 초안 수정 입력 제공 | API를 실제 사용 흐름으로 이용하고 상태·버전을 사용자에게 보여주기 위해 필요 |

## API

| 경로 | 역할 |
|---|---|
| `GET /api/v1/listings/mine` | 로그인 중개사의 전체 매물 목록 |
| `GET /api/v1/listings/mine/:id` | 로그인 중개사 소유 매물의 편집 정보 |
| `POST /api/v1/listings` | 새 매물을 `DRAFT`, 버전 1로 생성 |
| `PUT /api/v1/listings/:id` | 소유한 초안 또는 수정 필요 매물을 전달한 버전 기준으로 교체 |

쓰기 API는 인증 쿠키, `AGENT` 역할, 허용된 Origin, JSON 콘텐츠 유형, 현재 세션의 CSRF 토큰을 모두 요구한다. 다른 소유자의 매물은 `404`, 수정 불가능 상태나 오래된 버전은 `409`를 반환한다.

## 화면

- `/agent/listings`: 내 매물과 상태·버전 표시
- `/agent/listings/new`: 기본 정보, 구조, 주소 공개 범위, 거래 유형별 가격 입력
- `/agent/listings/[id]/edit`: 최신 편집 데이터 조회 후 수정
- 계정 화면의 중개사 전용 `내 매물 관리` 링크

로컬 시드 중개사 계정은 `seed-agent@local.invalid`이며 비밀번호는 `LocalAgentPassword123!`이다. 실제 서비스용 계정이 아니며 로컬·테스트 환경에서만 사용한다.

## 검증 결과

- API·웹 타입 검사와 린트 성공
- API 단위 테스트 4건 성공
- 실제 PostgreSQL·Redis 통합 테스트 전체 성공
- 소유 중개사 생성·목록·수정 성공
- 다른 중개사의 상세 조회·수정 `404`
- 오래된 버전 재수정 `409`
- 생성된 초안의 공개 상세 조회 `404`
- 생성·수정 이력, 가격 이력, 감사 로그 각각 2건 확인
- Next.js 프로덕션 빌드 및 신규 3개 화면 라우트 생성 확인
