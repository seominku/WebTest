# 원본 화면 GitHub Pages 미리보기

## 변경 목적과 범위

사용자가 기존 간소화 데모 대신 원본 디자인과 화면을 요청했으며 실제 서비스는 운영하지 않기로 했다. 공개 주소는 https://seominku.github.io/WebTest/ 를 유지한다.

`apps/web`의 원본 Next.js 페이지·컴포넌트·스타일을 그대로 복사해 정적 HTML로 빌드한다. 홈, 목록, 상세, 로그인, 회원가입 및 계정 관련 경로가 포함되며 인증 전용 화면은 원본의 비로그인 안내 상태로 표시된다. 가짜 로그인이나 관리자 권한을 만들지 않는다.

- 동작: 페이지 이동, 가상 매물 3개의 목록/상세, 지도/묶음 마커/옆 패널, 사진 전환, 면적 단위 전환, 브라우저 내 최근 조회 기록.
- 미제공: 로그인·회원가입·조건 검색·매물 등록/수정·문의·방문 일정·관심 저장 등 서버 기능. 주변 시설 외부 조회도 비활성.
- 원본 유지: 앱/API/DB 소스, 로컬 Docker 설정과 데이터를 변경하지 않는다. 배포용 변환은 `.artifacts/pages-original-*` 사본에만 적용한다.
- 이전 간소화 데모의 HTML/CSS/JS 및 빌드/테스트 파일은 제거하며 필요 시 기존 커밋 `7347f8c`에서 복구할 수 있다.

## 구성과 안전장치

1. `scripts/build-pages-original.mjs`가 원본 `src`, 지정 설정 파일, 기존 공개 AI 샘플 사진만 새 임시 디렉터리에 복사한다. `.env`, DB, 백업, 보고서, 실행 로그, 기존 빌드 결과를 복사하지 않는다.
2. `infrastructure/pages`의 가상 데이터와 API 차단 구현을 복사본에만 덮어쓴다. 원본 데이터베이스 및 실제 API는 조회하지 않는다. 가상 연락처·등록번호를 사용한다.
3. 서버 검색 파라미터를 고정하고 샘플 상세 ID를 사전 생성한다. 건강 확인 API 경로는 배포에서 제외한다. 공개용 설정은 `output: export`, `basePath: /WebTest`, `trailingSlash: true`, 이미지 최적화 서버 미사용이다.
4. 모든 원본 form을 disabled fieldset으로 감싼다. JavaScript 실행 전에도 입력/제출을 차단한다. API 대체 구현은 인증/쓰기 요청을 네트워크 전송 없이 거부하며 가짜 성공 결과를 반환하지 않는다.
5. 원본 상단에 서비스 미운영·가상 데이터·서버 기능 비활성 안내를 추가한다. 지도/CDN은 기존 OpenStreetMap/unpkg 공개 자원을 사용한다. 주소나 입력값을 외부 시설 API로 보내지 않는다.
6. 원본 지도 패널의 일반 링크와 샘플 사진 경로에 `/WebTest`를 붙인다. 원본과 다른 구조가 발견되면 명시적 변환 검사에서 빌드를 중단하여 조용한 오작동을 방지한다.
7. `.github/workflows/pages-demo.yml`의 `Deploy original website preview`가 테스트·격리 빌드·산출물 검증 후 **out 폴더만** 게시한다. 이 방식은 서버나 DB의 호스팅이 아니다.

## 점검 및 재배포

```powershell
node --test scripts/pages-original.test.mjs
node scripts/build-pages-original.mjs
$env:CHECK_PAGES_OUTPUT='1'
node --test scripts/pages-original.test.mjs
node scripts/serve-pages-original.mjs
```

로컬 미리보기는 `http://127.0.0.1:4321/WebTest/`이며 이 프로세스는 점검 후 종료한다. 운영 서버는 시작하지 않는다. 관련 원본 소스, 어댑터, 잠금 파일 변경을 `main`에 푸시하면 같은 공개 주소에 자동 배포된다. 원본 기능 변경으로 어댑터 검사가 실패하면 변환 지점을 검토한 뒤 재시도한다.

## 되돌리기

이번 Pages 워크플로/빌드/어댑터 변경을 별도 되돌림 커밋으로 복원하고 재배포한다. 필요하면 Pages 게시만 해제한다. 원본 앱이나 데이터 복구는 필요 없다. 보존된 로컬 WT 보고서 관련 미커밋 기록은 이 배포에 포함하지 않는다.
