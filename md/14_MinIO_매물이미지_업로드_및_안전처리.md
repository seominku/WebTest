# MinIO 매물 이미지 업로드 및 안전 처리

> 이후 비동기 악성코드 검사와 썸네일 처리는 [ClamAV 비동기 이미지 검사 및 썸네일](./15_ClamAV_비동기이미지검사_및_썸네일.md)에서 확장했다. 아래 내용은 최초 동기 처리 단계의 설계 기록이다.

## 완료 결과

중개사가 초안을 저장한 뒤 매물 이미지를 등록하고, 순서를 바꾸고, 삭제할 수 있다. 첫 번째 이미지가 대표 이미지가 되며 공개 목록과 상세 화면에 실제 사진이 표시된다. 초안 이미지는 소유 중개사만 볼 수 있고 매물이 게시된 기간에만 공개 이미지 주소가 응답한다.

## 구성 요소와 필요한 이유

| 구성 요소 | 역할 | 필요한 이유 |
| --- | --- | --- |
| Multer 메모리 업로드 | 파일을 임시 디스크에 남기지 않고 크기를 10MB로 제한 | 임시 파일 유출과 과도한 디스크 사용을 줄이기 위해 필요 |
| `file-type` | 확장자가 아니라 실제 파일 바이트 서명으로 JPEG·PNG·WebP 판별 | 실행 파일의 이름만 이미지로 바꾼 업로드를 거부하기 위해 필요 |
| `sharp` | 실제 이미지 디코딩, 방향 보정, 크기 확인, WebP 재인코딩 | 손상 이미지와 과도한 픽셀 이미지를 거부하고 EXIF 등 불필요한 메타데이터를 제거하기 위해 필요 |
| MinIO | 정규화된 이미지 원본 저장 | 큰 바이너리 파일을 PostgreSQL과 분리하고 S3 호환 방식으로 확장하기 위해 필요 |
| `ListingImage` | 객체 키, 해시, 크기, 가로·세로, 순서와 상태 저장 | 파일의 소유 관계와 대표 순서를 데이터베이스에서 일관되게 관리하기 위해 필요 |
| 버전 검사 | 업로드·삭제·정렬마다 매물 버전 증가 | 동시에 열린 오래된 화면이 최신 이미지 구성을 덮어쓰지 못하게 하기 위해 필요 |
| 이미지 프록시 API | 소유권 또는 공개 상태를 검사한 뒤 MinIO 파일 전달 | 비공개 버킷을 유지하면서 허가된 이미지만 브라우저에 제공하기 위해 필요 |

## 업로드 정책

- 허용 형식: JPEG, PNG, WebP
- 파일당 최대 크기: 10MB
- 최소 해상도: 640×480
- 최대 입력 픽셀: 4천만 픽셀
- 매물당 최대 개수: 20장
- 같은 매물 안에서 동일한 정규화 이미지 해시 중복 금지
- 저장 형식: 품질 85의 WebP
- 사용자가 보낸 파일명은 저장 키에 사용하지 않고 UUID를 사용
- 이미지 변경 가능 상태: `DRAFT`, `NEEDS_CHANGES`
- 검수 요청 조건: `READY` 이미지 최소 1장

## 저장과 공개 흐름

1. 브라우저가 파일과 현재 매물 버전을 `multipart/form-data`로 전송한다.
2. API가 크기와 실제 파일 서명을 검사한다.
3. `sharp`가 이미지를 디코딩하고 방향을 보정한 뒤 WebP로 다시 인코딩한다.
4. 정규화 파일의 SHA-256 해시와 크기·가로·세로를 계산한다.
5. MinIO의 `listing-images/{listingId}/{uuid}.webp` 키에 저장한다.
6. PostgreSQL 트랜잭션이 매물 버전, 이미지 레코드, 변경 이력, 감사 로그를 함께 기록한다.
7. 데이터베이스 저장이 실패하면 먼저 저장한 MinIO 객체를 정리한다.
8. 공개 이미지 API는 매물이 현재 `PUBLISHED`이고 게시 기간이 남았을 때만 파일을 반환한다.

## API

- `POST /api/v1/listings/mine/:id/images`
- `PUT /api/v1/listings/mine/:id/images/order`
- `DELETE /api/v1/listings/mine/:id/images/:imageId`
- `GET /api/v1/listings/mine/:id/images/:imageId/content`
- `GET /api/v1/listings/:id/images/:imageId/content`

변경 API에는 로그인, 중개사 역할, Origin, CSRF, 소유권, 상태, 버전 검사가 적용된다. 업로드 API는 브라우저가 multipart 경계값을 자동 생성하도록 `Content-Type`을 직접 덮어쓰지 않는다.

## 화면 동작

- 새 매물 초안을 저장하면 해당 매물 수정 화면으로 이동한다.
- 여러 이미지를 선택하면 한 장씩 버전을 갱신하며 업로드한다.
- 현재 이미지 수, 크기, 해상도와 대표 이미지 표시를 제공한다.
- 화살표 버튼으로 순서를 바꾸며 맨 앞 이미지가 대표 이미지가 된다.
- 공개 목록 카드에는 대표 이미지가, 상세 화면에는 전체 이미지가 표시된다.

## 검증 범위

- 실제 PNG 업로드 후 MinIO에서 WebP 반환
- 최소 크기 미달 이미지 거부
- 같은 이미지 중복 업로드 거부
- 다른 중개사의 초안 이미지 접근 거부
- 초안 이미지 공개 접근 거부
- 이미지 정렬·대표 변경·삭제와 버전 증가
- 게시 후 공개 이미지 `200`, 게시 중지 후 `404`
- 이미지 변경 이력과 감사 로그 수 확인
