# 운영 공개 전 남은 조건

## 현재 판단

로컬 주요 기능과 운영 상태 점검은 통과했지만 외부 공개 준비 완료를 의미하지 않는다. 현재 루트 Compose는 `APP_ENV=local`, localhost 주소, 로컬 계정·설정에 맞춰져 있다. 이를 그대로 인터넷에 노출하지 않는다. 이 문서는 배포 승인이나 법적 적합성 판단이 아니다.

## 우선 처리 항목

| 항목 | 확인된 근거·상태 | 완료 조건 |
| --- | --- | --- |
| 배포 대상·도메인 | 외부 배포 대상 미정 | 사용자 선택과 비용·공개 범위 승인 후 별도 배포 구성 |
| HTTPS와 인증 쿠키 | `auth-cookie.ts`는 `APP_ENV=production`에서만 Secure·`__Host-` 쿠키 사용. 루트 Compose는 local 고정 | HTTPS 환경에서 로그인·CSRF·로그아웃 검증. 쿠키 설정만 바꿔 로컬 접속을 깨뜨리지 않음 |
| 웹/API 주소·프록시 | Compose의 WEB_ORIGIN, 브라우저 API 주소가 localhost 기준. TRUST_PROXY_HOPS=0 | 실제 도메인·프록시 구조에 맞춰 CORS·API URL·신뢰 프록시 범위를 함께 검증 |
| 실제 이메일 인증 | `AuthService.register`는 토큰 생성·저장 및 local/test 응답 반환 경로만 연결. 확인한 등록 경로에 메일 발송 없음 | 승인된 메일 제공자와 재시도·실패 안내·재발송 정책 구현 및 수신 검증. 주소 전송은 승인 후 수행 |
| 운영용 비밀값 | 예제 설정·로컬용 기본값 존재. 실제 비밀값은 이 문서에 수집하지 않음 | 별도 운영 계정·키 발급, 기본값 차단, 비밀 저장·교체 절차 |
| 샘플·QA 데이터 분리 | 로컬 시드와 QA 기록 유지 중 | 운영 DB에 샘플 계정·가상 사진·QA 매물을 이관하지 않도록 별도 데이터 준비 |
| 백업과 사진 복구 | 25·26번 복원 검증 통과. 27번 권한 점검에서 평문 파일·상속 접근 규칙 확인, 자동 삭제 없음 | 암호화 키 방식 선택 후 암호화·복호화 검증과 허용 주체 확인. 보관 기간·외부 위치·시점 복구 기준은 별도 |
| 경보 종단 전달 | 22번 실제 모니터링 격리 훈련에서 가상 지표 장애의 경보 발생·수신·해제 확인 완료 | 기존 앱의 개별 장애 조건 및 외부 수신 채널은 별도 검증·승인 |
| 실제 인프라 장애 | 28번 격리 실제 중단 4종 통과. DB 장애 시 API 종료 문제·오류 안내 보완, 29번에서 기존 로컬 API 적용 및 정상 업로드 검증 완료 | 장시간·동시 장애·사진 전송 중 실패·웹 오류 화면은 별도 |
| 실제 휴대폰 | 브라우저 좁은 화면 검증 완료, 실기기 키보드·터치 미검증 | iPhone/Safari·Android에서 등록·사진·지도·면적 전환 확인 |
| 이미지 버전·부하 | 일부 기반 이미지가 latest/stable 태그. 로컬 통과가 운영 용량 보장은 아님 | 배포 이미지 digest 고정·관련 보안 점검·정해진 트래픽 기준 부하 시험 |
| 운영 안내·권한 | 외부 전송 동의는 보류 중 | 실제 사진 사용 권한, 사용자 안내, 개인정보 처리·보관 정책을 확정하고 필요한 검토 수행 |

주소 지오코딩과 외부 경보 전송은 사용자가 승인하지 않아 계속 비활성으로 둔다. 이 상태를 이유로 임의로 공급자 계정·도메인·유료 서버를 생성하거나 공개하지 않는다.

## 다음 순서

1. 완료: 격리 모니터링 구성에서 실제 경보 발생·전달·해제 검증 및 훈련 자원 정리.
2. 완료: DB·READY 사진 묶음의 실제 격리 복원 및 원본 없는 기존 백업 검증, 실제 DB·Redis·사진 저장소·검사기의 단기 중단 후 앱 회복 검증, 수정 API의 기존 로컬 서버 적용. 남음: 백업 보호·보관 정책, 장시간·동시 장애와 웹·실기기 확인.
3. 사용자에게 배포 대상·도메인·메일 제공자 선택이 필요한 시점에 구체적인 결정을 요청한다. 승인 전에도 외부 전송 없는 코드·설정 검증은 진행할 수 있다.
4. 실제 배포 대상이 정해진 뒤 전용 보안 설정과 공개 전 체크를 검증한다.

체크리스트 항목은 구현·검증 근거가 있을 때만 완료로 바꾼다. 원본 운영 설정 전환과 데이터 이관은 수행하지 않았다. 임시 테스트 환경의 별도 설정과 가상 계정 생성/외부 접속 범위는 30번 문서에 한정한다.
