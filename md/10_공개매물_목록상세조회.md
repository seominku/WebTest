# 공개 매물 목록·상세 조회

## 작업 결과

PostgreSQL의 매물·부동산·주소·중개사 데이터를 연결해 공개 매물 목록과 상세 API를 만들고 Next.js 화면에 표시했다. 거래 유형, 매물 유형, 시·도, 시·군·구 필터와 페이지 정보를 제공하며 승인되지 않은 초안·만료·삭제·비활성 중개사 데이터는 공개하지 않는다.

## 구성 요소의 역할과 필요한 이유

| 구성 요소 | 역할 | 필요한 이유 |
|---|---|---|
| `ListingsService` 공개 조건 | 게시 상태·기간·삭제 여부와 중개사무소·중개사·계정 활성 상태를 함께 검사 | DB에 존재하지만 공개하면 안 되는 초안·정지 계정 매물이 실수로 노출되는 일을 막기 위해 필요 |
| 목록 DTO | 거래·매물·지역 필터와 페이지·페이지 크기를 검증 | 잘못된 enum이나 과도한 페이지 크기가 DB 쿼리까지 전달되지 않게 하기 위해 필요 |
| 문자열 가격 계약 | PostgreSQL `BIGINT` 가격을 문자열로 API 전송 | JavaScript 숫자의 안전 정수 범위를 넘는 가격도 반올림 없이 전달하기 위해 필요 |
| 주소 공개 변환 | `PUBLIC`만 도로명 주소를 제공하고 나머지는 동 단위만 제공 | 매물 검색 편의성과 거주자 개인정보 보호를 함께 지키기 위해 필요 |
| 공개 캐시 정책 | 30초 캐시와 120초 stale-while-revalidate 설정 | 매물 목록의 반복 DB 조회를 줄이면서 게시 변경이 비교적 빠르게 반영되게 하기 위해 필요 |
| Next.js 서버 데이터 호출 | 웹 서버가 내부 Docker 주소로 API를 호출하고 30초 단위로 재검증 | 브라우저에 내부 서비스 주소를 노출하지 않고 초기 HTML에 매물 내용을 포함하기 위해 필요 |
| 로딩·오류·빈 상태 | 데이터 대기, API 장애, 검색 결과 없음에 각각 다른 화면 제공 | 사용자가 멈춤·장애·결과 없음의 원인을 구분할 수 있게 하기 위해 필요 |
| 가상 시드 | 승인된 공개 매물 3건과 비공개 초안 1건을 고정 UUID로 upsert | 실제 개인정보 없이 목록·필터·보안 조건을 반복해서 검증하기 위해 필요 |

## 공개 조건

다음 조건을 모두 만족해야 목록과 상세에서 조회된다.

1. 매물 상태가 `PUBLISHED`이다.
2. `published_at`이 현재 시각 이전이다.
3. `expires_at`이 없거나 현재 시각 이후이다.
4. 매물과 물리적 부동산이 소프트 삭제되지 않았다.
5. 중개사무소와 중개사 프로필이 `ACTIVE`이다.
6. 중개사 사용자 계정이 `ACTIVE`이고 삭제되지 않았다.
7. 주소 레코드가 존재한다.

목록과 상세가 같은 조건 생성 함수를 사용하므로 목록에서 사라진 비공개 매물을 UUID로 직접 요청해도 `404`가 반환된다.

## API

| 경로 | 역할 |
|---|---|
| `GET /api/v1/listings` | 공개 매물 목록, 페이지네이션과 필터 |
| `GET /api/v1/listings/:id` | 공개 매물 상세 |

목록 필터는 `transactionType`, `propertyType`, `sido`, `sigungu`, `page`, `pageSize`이며 `pageSize`는 최대 50이다. 현재 정렬은 최신 게시 순으로 고정했다.

## 화면

- `/listings`: 검색 조건, 결과 수, 매물 카드, 빈 결과, 페이지 이동
- `/listings/[id]`: 거래 가격, 면적·층·방·욕실, 설명, 공개 가능한 위치, 중개사무소 정보
- 실제 이미지가 아직 없으므로 이미지 영역은 명확한 준비 중 대체 화면을 사용한다.
- 주소 공개 범위가 제한된 매물은 동 단위 위치와 개인정보 보호 안내를 표시한다.

## 검증 결과

- API DTO: 잘못된 매물 유형과 UUID에 `400`
- 실제 Docker API: 공개 매물 3건과 페이지 정보 확인
- 필터: 월세 1건, 서울특별시 2건 확인
- 가격: 숫자가 아닌 문자열 전송 확인
- 주소: `APPROXIMATE` 도로명 미노출, `PUBLIC` 도로명 노출 확인
- 비공개 초안: 목록 미노출 및 직접 UUID 요청 `404`
- 공개 응답 캐시 헤더 확인
- Chrome: 목록·상세 레이아웃, 링크, 접근성 이름, 브라우저 오류 없음 확인
- 기존 인증 스모크 테스트 재통과
